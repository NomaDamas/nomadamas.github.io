# 검색 노출: 글 한 편

글 한 편이 검색엔진과 AI 답변에 잡히도록 검수할 때와 발행한 뒤에 할 일이다. 블로그가 검색에 안 나오는 원인을 찾거나 실적을 잴 때는 `search-audit.md`를 본다.

## 목차

- 검색 키워드 점검
- 발행 뒤 알림과 색인 요청

## 검색 키워드 점검

목차 확인 때 정한 검색 키워드가 검색엔진과 AI 답변이 읽는 자리에 들어갔는지 본다. 본문에 많이 나와도 제목, 설명문, 소제목에 없으면 그 키워드로 잡히지 않는다.

1. 키워드마다 아래 자리에 몇 번 나오는지 센다. 링크 주소 안의 글자는 빼고 센다.
    - frontmatter의 `title`, `description`, `tags`
    - 소제목(`##`, `###`)
    - 도입 두 문단과 요약 박스
    - FAQ 질문과 답
    - 이미지 대체 텍스트
2. 핵심 키워드는 제목, 설명문, 소제목 하나 이상, 도입에 들어가야 한다. 빠진 자리는 문장이 자연스러운 범위에서 넣는다. 소제목에 키워드를 괄호로 덧붙이는 식으로 어색해지면 넣지 않는다.
3. 영어 키워드는 설명문, 요약, 영어 FAQ 문항 하나에 넣는다. 영어로 묻는 AI 검색이 그대로 인용할 문장이 생긴다.
4. 영어 제품명은 한국어 표기(클로드 코드, 감마, 젠스파크)도 따로 센다. 한국어로 검색하는 독자가 많은데 영어로만 쓰면 그 검색에 걸리지 않는다. 처음 나오는 곳에 괄호로 한 번 넣으면 된다.
5. 지운 절의 태그처럼 본문에 근거가 없는 태그는 뺀다.
6. 빌드 결과물에서 `<title>`과 `description` 메타 태그에 바뀐 문구가 나오는지 확인한다.

## 발행 뒤 알림과 색인 요청

네이버와 Bing에는 배포가 IndexNow로 알린다. Google은 IndexNow를 받지 않아 Search Console에서 따로 요청한다. 알리지 않은 새 글은 사이트맵을 다시 읽을 때까지 검색엔진이 모른다.

1. 배포 실행의 `indexnow` 잡 로그에서 보낸 주소와 응답을 본다(`gh run view <실행 번호> --job <indexnow 잡 번호> --log`).
    - 응답 코드의 뜻, 다시 보내는 법, 반복 전송 금지는 이 저장소 `AGENTS.md`의 "IndexNow" 절이 정본이다.
    - "알릴 주소가 없습니다"는 그 푸시에 글 변경이 없었다는 뜻이다. 글을 더하거나 고친 머지에서 이 줄이 나오면 위 절대로 다시 보내고(승인 대상), 스크립트가 놓친 원인은 이슈 후보로 사용자에게 알린다.
2. 새 글 주소(`https://blog.nomadamas.org/posts/<slug>/`)를 Search Console에서 색인 생성 요청한다. API가 없어 소유자 화면을 `scripts/request_index.py`로 조작한다.
    - `--account`(소유자로 로그인된 Aside 계정), `--property`, `--google-account` 값은 이 저장소의 운영 문서에서 읽는다. 화면의 Google 계정이 다르면 스크립트가 누르지 않고 멈춘다. 다른 계정에서 제출이 나가지 않게 하려는 것이다.
    - 먼저 `--no-submit`으로 돌려 입력칸과 버튼을 찾는지 본다. 화면 조회만 하므로 승인 없이 돌려도 된다. 화면이 바뀌어 `failed`가 나오면 아래 함정을 보고 스크립트를 고친다.
    - 실제 요청은 사이트 제출이라 주소를 밝혀 승인받는다(`SKILL.md` 승인 경계).
3. 하루 이틀 뒤 URL 검사로 상태를 다시 본다. 조회는 서비스 계정 API로 해서 승인이 필요 없다. 여전히 "Google에는 아직 알려지지 않은 URL입니다."면 `search-audit.md` "막힌 단계 찾기"의 발견 단계부터 본다.

스크립트가 깨졌을 때 손으로 할 때의 화면 함정:

- 검사 주소(`search-console/inspect?...&id=<주소>`)를 직접 열면 404다. 상단 URL 검사 입력칸에 주소를 넣는다.
- 버튼 이름은 상태에 따라 "색인 생성 요청" 뒤에 글자가 붙는다("색인 생성 요청다시 요청"). 정확히 일치로 찾지 않는다.
- 누르면 실제 URL 테스트를 거쳐 건당 30초 안팎 뒤에 "색인 생성 요청됨" 창이 뜬다. reCAPTCHA가 붙어 있다.
- 할당량 문구가 뜨면 그날은 더 보내지 않는다.
- 로딩 중 접근성 트리에는 계정 버튼이 빠질 수 있다. 계정 확인은 몇 번 다시 본다.
